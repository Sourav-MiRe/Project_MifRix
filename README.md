# MifRix (Microbiome-inferred Risk-scores with explainability)
This repository contains the R scripts, input data, and supporting files used in the analyses described in the manuscript "MifRix: An Integrated microbiome framework for predicting generic and disease-specific risks investigating inter-disease diagnostic cross-talks and intra-disease signature variability"

The entire MifRix pipeline can be accessed through-
https://github.com/Sourav-MiRe/MifRix
